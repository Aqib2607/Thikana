# Thikana Frontend

The frontend for **Thikana (ঠিকানা)** is built with TanStack Start (React 19 + Nitro SSR), Tailwind CSS v4, and Radix UI primitives.

For complete project documentation, system architecture, feature breakdown, testing guides, and credentials, please refer to the root [README.md](../README.md).

## Local Development

```bash
# Install dependencies
npm install

# Start Vite dev server on port 3000
npm run dev

# Run Vitest test suite (71 tests)
npm test -- --run

# Run TypeScript type check
npx tsc --noEmit

# Build production bundle
npm run build
```
